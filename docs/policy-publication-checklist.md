# 공개 전 정책 확인사항

현재 관리자 설정의 개인정보처리방침과 이용약관은 코드에서 확인한 기능과 2026-10-28 제공받은 운영자 정보를 기준으로 작성했다. 공개 배포 전 아래 사실관계를 확인하고 해당 문구를 갱신한다.

1. 택배사 확정 후 개인정보처리방침의 배송 관련 제공·위탁 업체명, 항목, 목적과 배송 안내를 실제 계약에 맞게 수정한다.
2. Netlify·Neon의 실제 데이터 처리 지역, 국외 이전 여부, 수탁자 정보와 관련 고지 요건을 확인한다. 국외 이전이 발생하면 법령상 필요한 정보를 개인정보처리방침에 구체적으로 공개한다.
3. 회원 탈퇴 및 삭제 요청을 이메일·전화로 실제 처리할 수 있는 운영 절차를 마련한다. 사이트에서 전자적으로 가입받는 서비스인 만큼 전자적 탈퇴 경로 제공 요건도 검토한다.
4. 광고 서비스를 활성화하면 쿠키·행태정보 처리 내용과 거부 방법을 실제 설정에 맞게 추가한다.
5. 사업자등록번호·통신판매업 신고번호 등 상거래 화면의 법정 표시정보와 교환·환불 운영 절차를 확인한다.

참고: 개인정보 보호법 제30조, 제28조의8, 전자상거래 등에서의 소비자보호에 관한 법률 및 시행령 제6조.
