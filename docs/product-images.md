# 상품 사진 운영

- 관리자 상품 등록·수정에서 JPG, PNG, WebP 파일(최대 3MB)을 선택합니다.
- 업로드 후 상품을 저장해야 사진이 상품에 연결됩니다. 교체·제거도 상품 저장 시 적용됩니다.
- 서버는 이미지 내용을 검사하고 최대 1600px WebP로 변환합니다. EXIF 등 원본 메타데이터는 보존하지 않습니다.
- 운영은 Netlify Blobs의 `product-images` 저장소를 사용합니다. Netlify 런타임에서 저장소 자격 증명을 주입합니다. 재배포해도 사진은 유지됩니다.
- 미리보기 배포는 CONTEXT별 별도 저장소를 사용합니다. 운영 DB와 미리보기 DB도 분리해야 합니다.
- `npm run dev`는 `.local/product-images`에 사진을 저장합니다. 로컬 사진은 배포되지 않습니다.
- 로컬 업로드 검증: `npm run dev:check` 실행 후 `npm run test:uploads`. 테스트는 DB 상품과 소개 내용을 변경하지 않습니다.
- 사진 교체 시 기존 파일은 즉시 삭제하지 않습니다. 이전 주문·열린 화면의 이미지가 깨지지 않도록 보존하며, 연결되지 않은 파일 정리는 별도 운영 작업으로 수행합니다.
- 배포 전 Netlify Node.js 런타임 22.12 이상을 확인하고, 실제 관리자 업로드·저장·재접속 검증을 수행합니다.
